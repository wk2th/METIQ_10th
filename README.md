# METIQ 公式ホームページ

見た目は 1996 年のホームページ。中身は Rust → WebAssembly (SIMD) のレンダリングカーネル。

- **スクショすると普通の昔のページ**になります。演出はすべてマウスの動きに比例する
  1 本のエネルギー値で駆動され、止まると約 2 秒で完全にゼロへ戻ります（DOM 上にも
  transform が 1 つも残りません）。さらに PrintScreen / ⌘⇧ / ⊞⇧ / ウィンドウの
  フォーカス喪失 / タブ非表示 / 印刷 を検知した瞬間に同期的に全演出を停止します。
- JavaScript が無効でも、HTML 3.2 (quirks mode) のただの古いページとして表示されます。

## 演出一覧

| 場所 | 静止時 (スクショ) | 動かすと |
|---|---|---|
| 文字にカーソルを合わせる（2 文字ほど動くたび） | 普通のテキスト | カーソルの文字から崩壊が隣の文字へランダムに伝わっていく（上下の行にも。毎回ちがう形・広さ、途中で止まる所や取り残される所がある）。文字化け（縺繧 / ｮｯÃ©）→ ギリシャ文字 → 数式記号 → 正しい文字、と計算し直されるように復元 |
| 表や画像（オブジェクト）に近づく | 普通の表・画像 | 細胞のように生きて見える：表面が液体の膜のようにゆらぎ、角が丸くなり、ゆっくり伸び縮みして呼吸し、ときどきピクピクと細動する。下の縁に透明でつやのあるしずくがふくらみ、くびれて落ちていく。離れると数秒で完全に静止する |
| 約 10 秒に 1 回 | — | 画面内の表・画像（ロゴ、メダル、カウンター、地球儀など）のどれかが、次の 5 通りのどれかで破壊され、そのあとぼんやり光りながらふわっと再生する（文字も復号される）。破片は最大 160 個、衝撃点の近くほど細かく、3D に回転しながら落ちる。黒焦げ・サビになってから割れ、落ちる途中も焦げ・サビが進む（フェードアウトせず画面外まで落ちる） |
| 　電撃 | — | 青白い電気がひびを走り、黒焦げになって砕け散る |
| 　サビ | — | サビが何か所からか広がり（文字も腐る）、サビた順にボロボロ崩れて落ちる |
| 　落雷 | — | 画面の上から枝分かれした雷が落ち、画面が白く光り、全体が黒焦げになって吹き飛ぶ |
| 　隕石 | — | 火の玉が斜めに飛んできて着弾、閃光・衝撃波・画面の揺れ、燃えて黒焦げになり爆発 |
| 　ハッキング | — | 緑の走査線とノイズ、文字が 16 進数に、端末が削除コマンドを打ち込み、横に裂けて消える |
| 　（試し方） | — | URL の末尾に `#electric` `#rust` `#lightning` `#meteor` `#hack`（または `#shatter` でランダム）を付けると 2 秒後に起きる |
| スマホで画面に触れる（複数の指も可） | — | 指ごとに、触れた場所から文字化けした文字が飛び散り（文字化け → ギリシャ文字 → 数式記号と変わりながら消える）、近くの文字から文字化けが広がる。なぞると軌跡に沿って続く |
| 本文の文字（マウスを速く動かす） | 普通のテキスト | 1 文字ずつのバネが震える・色収差 |
| ロゴ | 透過 GIF 風のドット絵（ブランドのスレート色・面取り・影） | 三角マークが頂点を軸に 3D 回転＋光沢、離すと 1 回転して正面で止まる。クリックで高速回転。静止中もときどき頂点がキラッと光る |
| 10周年メダル | 金ピカの 10th ANNIVERSARY メダル（ときどきキラッ） | 放射状の模様が回り、金属に光沢が走り、リボンが揺れ、キラキラが増える |
| 地球儀 | 24 コマの GIF 風回転 | 60fps で滑らかに回転、ドラッグで回せる、経緯線が光る |
| アクセスカウンター | 7 桁の数字 | 機械式ドラムが繰り上がり付きで回転、ホバー/クリックで桁が空転 |
| 工事中サイン | 8fps のテープ | テープ加速・回転灯がストロボ |
| 虹色ライン | 静止 | 色相が流れて縄跳びのように波打つ |
| バナー | 88×31 | 光沢が斜めに走る |
| 画面全体 | なし | ノイズ・走査線・VHS のロールバー・ときどき信号の乱れ |
| カーソル | なし | キラキラの軌跡 |

`prefers-reduced-motion` が有効な環境では、震え・ノイズ系の演出はすべて無効になります。

## 構成

```
core/            Rust (#![no_std], アロケータなし, wasm-bindgen なし)
  src/math.rs      libm なしの sin / exp2 / atan2 / 0x5f3759df
  src/field.rs     文字ごとのバネ場と、文字化け→復元
  src/spread.rs    崩壊の伝わり方（ランダム重みの最短経路＝浸透）
  src/life.rs      オブジェクトの膜のゆらぎ・呼吸・細動・しずく
  src/destroy.rs   破壊演出（電撃・サビ・落雷・隕石・ハッキング）と再生
  src/crt.rs       simd128 で 4 画素同時に xorshift するノイズ
  src/odometer.rs  繰り上がりする機械式カウンター
  src/globe.rs     レイキャスト地球儀 + Bayer ディザ + Web セーフ 216 色
  src/logo.rs      ロゴの三角マークを符号付き距離場 (SDF) で描画
  src/badge.rs     10周年記念メダル
  src/logo_data.rs ロゴ文字部分 (tools/logo2rs.py で生成)
  ...
site/            公開するファイル一式（静的ホスティングでそのまま動く）
  index.html       本文（「ここを編集」コメントの範囲を書き換えてください）
  js/*.mjs         ES モジュール
  wasm/            ビルド済み metiq_core.wasm
```

## ビルド・確認

```sh
rustup target add wasm32-unknown-unknown
./build.sh                       # core/ → site/wasm/metiq_core.wasm
python3 -m http.server -d site   # http://localhost:8000
```

`file://` では wasm を読み込めないので、ローカルでも HTTP サーバー経由で開いてください。

## 公開

`main` に push すると `.github/workflows/pages.yml` が wasm をビルドして GitHub Pages
へデプロイします（リポジトリ設定の Pages → Source を “GitHub Actions” にしてください）。

## カスタマイズ

- **本文**: `site/index.html` の「▼▼▼ ここから下の本文を編集してください ▼▼▼」の範囲。
  現在は「METIQ は高IQ団体です」以外は「準備中」のプレースホルダーです。
- **アクセスカウンター**: 本物のカウントにはサーバーが必要です。現状はブラウザごとの
  訪問回数 (`localStorage`) + `DATA-BASE` の値を表示します。`#counter` に
  `DATA-ENDPOINT="https://..."` を付けると、その URL に POST して返ってきた
  `{"count": n}` を表示します。
- キリ番（ゾロ目・末尾 000 / 777）を踏むとメッセージが点滅表示されます。
